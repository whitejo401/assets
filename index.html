스크롤·부하 확인

오로라·별 레이어는 뷰포트에 렌더링되지만 스크롤 값에 반응해 함께 흐르도록 구성되어 있습니다. 개발자 도구 Performance에서 스크롤 구간을 녹화하면 메인 스레드·GPU 부하를 비교하기 좋습니다.

기대 동작: 스크롤 중에도 rAF는 동일하게 돌고, 레이아웃/페인트는 주로 main 안의 텍스트 블록만 해당합니다. 버벅임이 보이면 브라우저·GPU 드라이버 또는 다른 탭을 함께 확인해 보세요.

같은 문단을 반복해 스크롤 거리만 늘립니다. 실제 제품에서는 여기에 섹션·카드·리스트를 두면 됩니다.

배경 애니메이션은 전체 화면 단위로 유지되므로, 긴 페이지에서도 “스크롤할수록 더 많은 픽셀을 그린다”는 식의 부하는 없습니다(캔버스 해상도는 창 크기에만 의존).

스크롤 끝까지 내려가 본 뒤, 다시 위로 올려 전환 시 프레임 드랍이 있는지 확인해 보세요.

긴 스크롤 테스트 구간

아래 블록은 스크롤 길이를 충분히 확보하기 위한 테스트 콘텐츠입니다. 페이지 하단으로 갈수록 오로라 레이어가 실제로 위로 밀려나듯 화면 밖으로 사라지는지 확인해 보세요.

테스트 포인트 01: 스크롤 초반 — 오로라가 선명하게 유지되는지 확인

스크롤이 시작될 때는 기존과 유사한 밝기와 채도로 오로라가 보여야 합니다.

테스트 포인트 02: 스크롤 중반 — 오로라가 위로 올라가는지 확인

중간 지점에서는 오로라/별 레이어가 실제로 위쪽으로 이동하며 뷰포트에서 차지하는 영역이 줄어들어야 합니다.

테스트 포인트 03: 스크롤 후반 — 렌더 면적이 작아지는지 확인

하단에 가까울수록 레이어의 실가시 영역이 줄어들고, 화면 밖 구간은 그리지 않아 성능 이득이 발생합니다.

테스트 포인트 04: 최하단 — 오로라가 완전히 사라지는지 확인

맨 아래에서는 오로라 레이어가 0에 가까워져 사실상 보이지 않아야 합니다.
