스크롤·부하 확인

오로라·별·그레인 레이어는 모두 position: fixed 이라 뷰포트에 붙어 있고, 스크롤해도 다시 그리는 영역 크기는 변하지 않습니다. 개발자 도구 Performance에서 스크롤 구간을 녹화하면 메인 스레드·GPU 부하를 비교하기 좋습니다.

기대 동작: 스크롤 중에도 rAF는 동일하게 돌고, 레이아웃/페인트는 주로 main 안의 텍스트 블록만 해당합니다. 버벅임이 보이면 브라우저·GPU 드라이버 또는 다른 탭을 함께 확인해 보세요.

같은 문단을 반복해 스크롤 거리만 늘립니다. 실제 제품에서는 여기에 섹션·카드·리스트를 두면 됩니다.

배경 애니메이션은 전체 화면 단위로 유지되므로, 긴 페이지에서도 “스크롤할수록 더 많은 픽셀을 그린다”는 식의 부하는 없습니다(캔버스 해상도는 창 크기에만 의존).

스크롤 끝까지 내려가 본 뒤, 다시 위로 올려 전환 시 프레임 드랍이 있는지 확인해 보세요.
